# Yang Mo — Academic Homepage

一个纯 HTML + CSS 的极简学术个人主页，不需要 React、Node.js 或任何构建工具。

## 在 VS Code 中预览

1. 安装 **Live Server** 扩展。
2. 右键 `index.html`。
3. 选择 **Open with Live Server**。

也可以直接在浏览器中打开 `index.html`。

## 修改内容

- 个人资料和论文：`index.html`
- 字体、间距和颜色：`style.css`

推送到名为 `username.github.io` 的仓库后，GitHub Pages 可以直接使用根目录下的 `index.html`。
